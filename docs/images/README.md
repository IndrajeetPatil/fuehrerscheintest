# Documentation illustrations

The generated illustrations use the palette and flat editorial linework in
[`DESIGN.md`](../../DESIGN.md). Prompts are kept next to each WebP so the
artwork can be regenerated consistently.

| Image | Used in | Description | Prompt |
| --- | --- | --- | --- |
| `data-pipeline.webp` | `README.md` | Question files are checked, built, and used by the browser app, which stores progress locally. | [`data-pipeline.prompt.txt`](data-pipeline.prompt.txt) |
| `architecture.webp` | `docs/architecture.md` | Browser UI, quiz and session state, storage, progress API, catalogue, and hosting. | [`architecture.prompt.txt`](architecture.prompt.txt) |
| `practice-answer-flow.webp` | `docs/architecture.md` | A practice answer is checked and committed to IndexedDB. | [`practice-answer-flow.prompt.txt`](practice-answer-flow.prompt.txt) |
| `git-workflow.webp` | `docs/development.md` | Feature branch, hooks, pull request, hosted checks, merge, and Pages. | [`git-workflow.prompt.txt`](git-workflow.prompt.txt) |
| `question-data-pipeline.webp` | `docs/question-data.md` | Question files, law links, and signs feed the catalogue and drawing build. | [`question-data-pipeline.prompt.txt`](question-data-pipeline.prompt.txt) |
| `mastery-states.webp` | `docs/quiz-design.md` | Question mastery states and the transitions between them. | [`mastery-states.prompt.txt`](mastery-states.prompt.txt) |
| `progress-record.webp` | `docs/progress-database.md` | Progress settings contain sessions, which contain answers. | [`progress-record.prompt.txt`](progress-record.prompt.txt) |
